- **Quanti:** **minimo 5, idealmente 10-15** prove

### 3. Dispense del docente
- **Nome file:** `dispensa-<argomento>.pdf`

### 4. Libro di testo (uno o due)
- **Nome file:** `libro-<autore>.pdf`

- **Nome file:** `note-mie-<argomento>.pdf` o `.md`
