# Note mie — Meccanica

Spazio per le tue annotazioni durante lo studio del libro di testo.

Una nota per argomento o per capitolo, formato libero. Esempi:
- `dubbi-su-cap-3.md` — domande aperte da chiedere a Maestro
- `intuizione-energia.md` — analogie tue che ti aiutano a tenere a mente
- `errori-fatti-esame-2023.md` — autopsia di un esame andato male

Maestro **può leggere** queste note se gliele citi esplicitamente — ad esempio: "Maestro, leggi `03-note-mie/dubbi-su-cap-3.md` e rispondi". Altrimenti resta in `01-banca-dati/` e `02-libro-di-testo/` come tutto il suo lavoro normale.
