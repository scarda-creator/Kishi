# Banca dati — Meccanica

Qui carichi il materiale che Maestro userà per costruire il libro di testo di Meccanica.

## Cosa caricare (in ordine di priorità)

### 1. Esami passati ⭐ massima priorità
Sono **la cosa più preziosa**. Maestro estrae da qui i tipi di esercizio che cadono davvero, i trabocchetti, la difficoltà reale.

- **Formato:** PDF o immagine (scansione)
- **Quanti:** **minimo 5, idealmente 10-15** prove, spalmate sugli ultimi 3-5 anni
- **Cosa includere:** scritto E orale se hai entrambi; soluzioni se le hai
- **Nome file:**
  - `esame-AAAA-MM-DD-scritto.pdf` (es. `esame-2024-07-15-scritto.pdf`)
  - `esame-AAAA-MM-DD-orale.pdf`
  - `esame-AAAA-MM-DD-soluzioni.pdf` (se separate)
  - Se non sai la data: `esame-AAAA-sessione-X.pdf` (es. `esame-2024-estiva-1.pdf`)

### 2. Slide del corso
La sequenza ufficiale del programma, secondo il docente.

- **Formato:** PDF
- **Nome file:**
  - `slide-cap-NN-<argomento>.pdf` se sono divise per capitolo (es. `slide-cap-03-lavoro-energia.pdf`)
  - `slide-completo.pdf` se è un unico file

### 3. Dispense del docente (se esistono)
Note del docente, polycopiati, appunti distribuiti.

- **Formato:** PDF
- **Nome file:** `dispensa-<argomento>.pdf` (es. `dispensa-corpo-rigido.pdf`)

### 4. Libro di testo (uno o due, non di più)
Il manuale di riferimento. Usato come ancora per le derivazioni e per citare.

- **Formato:** PDF se possibile (o sezioni)
- **Nome file:**
  - `libro-mazzoldi.pdf` (esempio classico per Meccanica a Sapienza)
  - `libro-mencuccini-silvestrini.pdf`
  - `libro-<autore>.pdf` in generale

### 5. Tue note di studio (opzionale, ma utile)
Se hai già preso appunti, mandali pure. Maestro li tratta come "come Giuseppe ha capito finora".

- **Formato:** PDF, immagine, o file `.md` se digitali
- **Nome file:** `note-mie-<argomento>.pdf` o `.md`

## Cosa NON caricare

- Esercizi da libri esterni al corso (Maestro li ignorerebbe — meglio puntare a ciò che il docente chiede davvero)
- Materiale di altri corsi
- Versioni multiple dello stesso file (tieni la più recente o la migliore)

## Quanto tempo ci vuole

- **Minimo per partire:** 5 esami + slide del corso = ~30 minuti per raccogliere
- **Ottimale:** 10-15 esami + slide + 1 libro = ~1-2 ore per raccogliere

Maestro lavora con quello che c'è. Più fonti hai, più il libro sarà tarato.

## Quando hai finito di caricare

Apri una nuova chat (con **Opus** selezionato), avvia il capitano, attiva Maestro, e dì:

> "Inventario di Meccanica."

Maestro fa la Fase 0 e ti dice cosa ha trovato e cosa eventualmente manca.
