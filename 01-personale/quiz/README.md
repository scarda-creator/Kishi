# Cartella `quiz/`

Sessioni quiz fatte con Pilot. Una sessione = un file.

## Convenzione nomi
`YYYY-MM-DD-<argomento>.md`
Esempio: `2026-06-06-meccanica-lavoro-energia.md`

## Struttura
Vedi `_template-sessione.md`.

## Come Pilot impara

Dopo ogni quiz, Pilot:
1. Salva la sessione qui
2. Aggiorna `studio/<argomento>.md` aggiungendo i punti deboli emersi
3. Nei quiz successivi, pesa di più quelle aree

Più sessioni fai, più il quiz diventa mirato.
