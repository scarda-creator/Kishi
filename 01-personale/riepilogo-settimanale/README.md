# Cartella `riepilogo-settimanale/`

Dove Pilot salva i riepiloghi totali della settimana.

## Convenzione nomi
`YYYY-WNN.md` dove WNN è il numero ISO della settimana (lun-dom).
Esempio: `2026-W23.md` = settimana del 1-7 giugno 2026.

## Struttura
Vedi `_template.md`. Pilot la riempie automaticamente leggendo `note-giornaliere/`, `journaling/` e `quiz/` dei 7 giorni precedenti.

## Quando
- Su richiesta esplicita ("Pilot, riepilogo settimanale")
- O di default la domenica sera
