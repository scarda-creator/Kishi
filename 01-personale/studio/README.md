# Cartella `studio/`

Una cartella per le materie/argomenti che Giuseppe sta studiando. Pilot la usa come base per la **modalità Quiz**.

## Come funziona

- Un file Markdown per materia: `meccanica.md`, `meccanica-quantistica.md`, ecc.
- Il file ha sempre la stessa struttura (vedi `_template.md`)
- Pilot legge il file prima di ogni quiz: programma, concetti chiave, punti deboli emersi
- Pilot **aggiorna** il file dopo ogni quiz: nuovi punti deboli emersi vanno in coda
