# Navicella — dati (Kishi)

Repository **PRIVATO**. Riversamento dello strato dati della navicella di Giuseppe Scarda.

- **L1–L4** (biblioteca, memoria operativa, documenti/opere) in chiaro.
- **L5** (substrato psicologico) è **cifrato** in `L5.enc`
  (Argon2id + XChaCha20-Poly1305, libsodium). La chiave NON è qui:
  vive solo nel dispositivo di Giuseppe e si digita al momento.
- Aggiornato da `00-capitano/scripts/riversamento/riversa.py`.

Non rendere pubblico questo repository.
